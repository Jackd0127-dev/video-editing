# Video editing skills

Claude Code skills for editing talking-head videos with [HyperFrames](https://hyperframes.heygen.com) and ffmpeg.

| Skill | What it does |
| --- | --- |
| [`30-day-ai-series`](skills/30-day-ai-series/SKILL.md) | Jack's "30 Day AI Series" look: clean ink-on-paper pages, word-synced captions above the head, animated logos, live infographics, carved music and a −14 LUFS master. |
| [`natural-clean-minimal`](skills/natural-clean-minimal/SKILL.md) | Natural, fast and minimal: one-word caps captions on the chest, quick-zoom hooks, punch-in jump cuts and premium liquid-glass overlays (banner titles, a pixel Claude character, typing comment composers). |
| [`arena-style`](skills/arena-style/SKILL.md) | Little animated pixel-art agents act out the video: they battle, fill a tournament bracket, get knocked out and the winner puts on a crown, on clean bone-paper pages and over untouched footage. |

## Install

Paste into Claude Code:

```
Install the video editing skills from
https://github.com/Jackd0127-dev/video-editing
Clone the repo, copy every folder in skills/ into ~/.claude/skills/,
install HyperFrames and ffmpeg if they're missing,
then list the editing styles you installed.
```

Fonts (Archivo, Playfair Display, IBM Plex Mono, Montserrat — all on Google Fonts) and sound effects are not included; bring your own.
